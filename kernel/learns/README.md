## 使用建议

### 如果你是内核检视新人

建议按目录编号顺序阅读：

1. 从 `learn.md` 开始，理解内核代码检视的核心哲学
2. 阅读 `01-review-核心协议/` ，掌握完整的检视方法论
3. 阅读 `03-技术模式/` ，学习跨子系统的通用技术模式
4. 使用 `04-子系统/00-子系统触发表.md` 导航到你关注的子系统
5. 深入 `04-子系统/` 中对应子系统的具体指南

### 如果你在处理内核崩溃

直接进入 `02-调试指南/` ，按调试协议的阶段一步步操作。

### 如果你在写 Coccinelle 补丁或做特定参考

查阅 `05-参考/` 中的对应文档。

## 与原仓库的关系

| 原仓库结构（agent 视角） | 本目录（学习者视角） |
|---|---|
| 技能 / 斜杠命令入口 | 目录编号 + README 导航 |
| YAML frontmatter + 工具声明 | 移除（无关学习内容） |
| "加载 X 文件"指令 | "阅读 X 章节"指引 |
| TodoWrite 任务清单 | 检查清单/验证方法 |
| agent 编排逻辑 | 无需保留 |
| 子系统 trigger 表 | 学习者导航索引 |

## 技术术语约定

英文技术术语在首次出现时标注中文翻译，例如：
- **dentry**（目录项）
- **folio**（页块）
- **rcu_read_lock** / **rcu_read_unlock**（RCU 读取侧临界区）

函数名、宏、结构体字段、代码片段保持英文原文。
